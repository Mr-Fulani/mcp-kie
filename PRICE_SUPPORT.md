# Поддержка тарифов для личного использования

На 2026-10-04 цены читаются из актуального KIE metadata при preview/prepare и ещё раз
перед execute. Числа не зашиты в код; нет общего предположения «один кредит = X USD».
Профили ниже проверяют полную формулировку тарифа и допустимые условия запроса.

| Модель | Проверенные условия | Live оценка примера |
|---|---|---:|
| z-image | Одно изображение, prompt/aspect_ratio | $0,004 |
| google/nano-banana | Одно изображение, png/jpeg, aspect_ratio | $0,02 |
| google/nano-banana-edit | Один входной image URL, один результат, png/jpeg | $0,02 |
| recraft/remove-background | Один image URL, одна операция | $0,005 |
| recraft/crisp-upscale | Один image URL, фиксированный upscale модели | $0,0025 |
| bytedance/v1-lite-text-to-video | 5/10 секунд, 480p/720p/1080p | $0,05 за 5s 480p |
| bytedance/v1-lite-image-to-video | Один начальный кадр, 5/10 секунд, 480p/720p/1080p | $0,05 за 5s 480p |
| bytedance/seedance-2-mini | 4–15 секунд, 480p/720p, без звука и входного видео; текст или один начальный кадр | $0,076 за 4s 480p |

Это оценки, а не гарантированная цена провайдера. Скидки за пополнение игнорируются.
Деньги округляются вверх до micro-USD; резервирование, лимиты и проверка свежей цены
остаются обязательными. KIE-side caps — независимая защита от превышения тарифа.
Изменённые/дополнительные условия цены, batch, неизвестные поля, дополнительные
кадры/видео или неподдержанное разрешение возвращают `confidence=unknown`.
В этом случае оценка остаётся `unknown`. Подготовка без согласия показывает
предупреждение и не создаёт резерв. После явного согласия пользователя можно
подготовить запрос на свой риск: ledger резервирует текущий per-task limit, а
фактическое списание KIE может оказаться выше. Exact-input owner quote остаётся
отдельным способом задать проверенную верхнюю границу.
После завершения MCP сообщит фактический USD только если KIE вернёт `costUsd` в
ответе задачи. Если поля нет, точная цена останется неизвестной; резерв ledger и
число кредитов не считаются фактическим USD.

Реализация: `src/kie_mcp/pricing.py`; исходный строгий unconditional parser и owner
quotes сохранены. Добавление нового профиля требует проверки live schema и полного
тарифа плюс регрессии, которые проверяют отказ на неизвестных условиях.
Discovery не ограничен этим списком: другие модели доступны через общие tools.
При неизвестном тарифе их можно подготовить только после отдельного согласия на риск.

Промопрофиль Mini действует до 2026-10-07 06:00 UTC. После этого времени даже старый
текст тарифа возвращает unknown; понадобится новый reviewed профиль, owner quote
или явное согласие на риск.
Входное видео, последний кадр, reference audio, автоматическая длительность `-1`,
web search и генерация звука не покрыты этим профилем.
