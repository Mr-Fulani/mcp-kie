# Verification evidence

Published reports are privacy-redacted historical evidence. Live media URLs,
private prompts, owner paths, raw CLI stdout/stderr and 32-character private
identifiers are omitted or consistently pseudonymised. Source schemas and request
hashes describe the original run and cannot be reconstructed from redacted payloads.
These reports are not runnable requests, active approvals or client configuration.

Original local reports and development history were preserved privately before
publication. No credentials, media files or private owner configuration belong here.
Use README/GETTING_STARTED/CHEATSHEET for current installation and commands.
