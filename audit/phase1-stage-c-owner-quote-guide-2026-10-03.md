# Ручная owner quote для тестового запроса z-image

Дата: 2026-10-03. Это сохранённая ручная инструкция, подготовленная до
авторизации установки. По последующему явному разрешению владельца котировка
установлена и проверена; **Stage C — PASS**, этап D не начат.
Для установленной котировки владелец подтвердил USD 0,004 / 0,8 credits,
источник <https://kie.ai/pricing>; срок — до 15:50:56 Europe/Istanbul.
Результат установки зафиксирован в отчёте C. Шаблон и предложение USD 0,01
ниже относятся к первоначальной ручной инструкции.
Основание: [отчёт C](phase1-stage-c-acceptance-2026-10-03.md) и
[сохранённые MCP-ответы](phase1-stage-c-live-dry-run-2026-10-03.json).

## 1. Проверить цену и точный запрос

Владелец проверяет текущий официальный тариф Z-Image в KIE для одного
изображения с параметрами ниже. В live metadata этапа C было указано
0,8 credits за изображение, приблизительно USD 0,004. Это опубликованное
описание; защитный расчёт вернул `confidence=unknown`.

Источник сохранённой цены: `live_kie_metadata:/api/v1/models/z-image/price`.
Документация модели: <https://docs.kie.ai/market/z-image/z-image.md>.
Для проверки USD используйте тариф этой модели; общий курс USD/credit и
скидку за пополнение для верхней оценки не предполагайте.

```json
{
  "model": "z-image",
  "input": {
    "prompt": "A single small green leaf centered on a plain white background, soft natural light, no text.",
    "aspect_ratio": "1:1"
  }
}
```

Request digest:
`80c20d439ee1efaa8e9f227f335d449d82c2ccb4625ac70e83298c304b19200b`.
Изменение model или input требует новой проверки и нового digest.

Предлагаемая верхняя оценка для этого одного теста — **USD 0,01**. Владелец
подтверждает, что она покрывает весь запрос при текущем тарифе. Это предложение,
а не уже подтверждённая цена. `max_cost_usd` задаёт локальную оценку для
резервирования бюджета; тариф и ограничения на стороне KIE она не меняет.

## 2. Заполнить котировку вручную

Шаблон ниже неактивен: `approved_by_owner=false`, `expires_at=0`.
После проверки владелец заполняет источник цены и срок, подтверждает верхнюю
оценку и сам меняет `approved_by_owner` на `true`.

```json
{
  "approved_by_owner": false,
  "request_digest": "80c20d439ee1efaa8e9f227f335d449d82c2ccb4625ac70e83298c304b19200b",
  "expires_at": 0,
  "max_cost_usd": 0.01,
  "estimated_credits": null,
  "pricing_source": "OWNER: replace with verified official z-image tariff, source URL and UTC verification time"
}
```

- `expires_at`: Unix timestamp в **секундах**, числом. Удобный срок —
  30 минут с момента подтверждения; не используйте миллисекунды или ISO-строку.
- `max_cost_usd`: подтверждённая владельцем консервативная верхняя оценка
  для всего запроса. Значение USD 0,01 укладывается в существующий лимит USD 1/task.
- `estimated_credits`: можно оставить `null`; поставить `0.8`, только если
  владелец подтвердил этот расход для точного запроса.
- `pricing_source`: замените шаблон описанием реально проверенного тарифа,
  его официальным источником и временем проверки. Секреты здесь не нужны.

Чтобы получить срок «сейчас + 30 минут», владелец выполняет:

```sh
python3 -c 'import time; print(int(time.time()) + 1800)'
```

Полученное число вставляется в `expires_at` до подключения котировки.

## 3. Сохранить приватный файл, затем подключить путь

Предлагаемый новый файл:
`/LOCAL_OWNER/.config/kie-mcp/owner-quote-z-image.json`.
На момент подготовки он отсутствовал; каталог имеет права `0700`.
Создание и редактирование выполняет сам владелец. Файл должен быть обычным,
не symlink, с правами `0600`; допустимый размер — не более 100 000 байт.

```sh
umask 077
nano /LOCAL_OWNER/.config/kie-mcp/owner-quote-z-image.json
chmod 600 /LOCAL_OWNER/.config/kie-mcp/owner-quote-z-image.json
```

После сохранения готовой котировки владелец сохраняет приватную копию текущей
конфигурации и открывает её для добавления одного параметра:

```sh
cp -p -n /LOCAL_OWNER/.config/kie-mcp/config.toml /LOCAL_OWNER/.config/kie-mcp/config.toml.owner-quote-backup-2026-10-03
nano /LOCAL_OWNER/.config/kie-mcp/config.toml
```

В **существующую секцию `[environment]`** добавить:

```toml
KIE_OWNER_QUOTE_PATH = "/LOCAL_OWNER/.config/kie-mcp/owner-quote-z-image.json"
```

Сохранить остальные значения. У config.toml должны остаться права `0600`.
Сначала сохраняется файл котировки, затем подключается его путь: настроенный
путь к отсутствующему файлу приведёт к ошибке проверки цены.

Launcher читает секцию `[environment]` при запуске, а сервер получает путь
через `KIE_OWNER_QUOTE_PATH`. Для применения нового пути нужен новый процесс
MCP через установленный launcher. После ручной настройки откройте новую сессию
Codex, чтобы запустить сервер с обновлённой конфигурацией.

## 4. Проверить принятие котировки через безопасный dry-run

В новой сессии вызвать защищённые MCP tools для **неизменённого** model/input:
`kie_estimate_cost`, затем `kie_create_task` с явным `dry_run=true`.

Ожидаемые поля:

| Поле | Ожидаемое значение |
| --- | --- |
| `confidence` | `estimated` |
| `owner_approved` | `true` |
| `pricing_source` | начинается с `owner_verified_quote:` |
| `estimated_cost_usd` | подтверждённый `max_cost_usd`, например `0.01` |
| `request_digest` | точное значение из этой инструкции |
| `dry_run` | `true` |
| `reservation_created` | `false` |
| `approval_id`, `task_id` | отсутствуют |

Успешный dry-run подтвердит принятие файла и привязку к точному запросу.
Если срок истёк, digest отличается или оценка остаётся `unknown`, остановиться
и согласовать следующий шаг. Не менять защиту и не создавать платную задачу.

Котировка сама по себе не запускает генерацию. Перед этапом D отдельно
согласовываются конкретный запрос и стоимость; затем prepare/execute
выполняются в одной MCP-сессии с неизменённым input. По умолчанию подготовленный
approval действует 300 секунд, поэтому prepare выполняется после согласования.
