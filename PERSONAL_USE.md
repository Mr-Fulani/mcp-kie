# Личное использование: статус и команды

Статус на 2026-10-04: личный image/video workflow проверен на реальном KIE.
Все шесть friendly-команд прошли подготовку, отправку и скачивание результата;
для `generate_video` проверены и текст, и оживление изображения.
Это приёмка выбранных моделей, а не обещание поддержки всех API/моделей KIE.

| Команда | Проверенная модель | Результат |
|---|---|---|
| generate_image | z-image | PNG 1024×1024 |
| edit_image | google/nano-banana-edit | Редактура фото; фактически JPEG 896×1200 |

## Выбор модели и сохранение результатов

Если модель не указана, любая friendly-команда теперь показывает варианты,
а не выбирает самую дешёвую автоматически. При каждом вызове список, схемы и цены
запрашиваются заново у KIE, без постоянного кэша. Актуальность зависит от каталога
самого KIE; наличие в списке не гарантирует успешную генерацию. При недоступности
обязательных live-данных команда сообщает ошибку, а не подставляет старый список.
Перед платной отправкой схема и цена проверяются снова. Агент должен показать пользователю
таблицу: модель, совместимость, длительность/разрешение/формат/звук, цена и источник
расчёта. Затем пользователь выбирает модель; команда вызывается с её `model`.
Цена относится к запрошенным или указанным по умолчанию параметрам, а не ко всем
режимам модели. Если MCP не определил цену, он показывает предупреждение; пользователь
может явно выбрать продолжение на свой риск. Локально резервируется per-task limit,
а фактическое списание KIE может быть выше. После завершения точный USD появится
только если KIE вернёт `costUsd`; кредиты и изменение баланса не переводятся в цену.
Проверенная владельцем котировка остаётся отдельным вариантом.

Для сравнения есть `kie_compare_models`: `operation` — имя friendly-команды,
`parameters` — параметры задачи, `query` — поиск, `cursor`/`next_cursor` — следующие
страницы. По умолчанию проверяются пять моделей на странице, максимум десять.
Несовместимые варианты показываются с причиной. Сравнение не загружает фото,
не резервирует деньги и не запускает генерацию. `include_metrics=true` добавляет
доступную статистику провайдера; качество и скорость независимо не измерены.
Если пользователь явно поручил выбрать самый дешёвый вариант, можно передать
`auto_select=true`: сравниваются первые 20 кандидатов с известной ценой и, если
задана длительность видео, с подтверждённой поддержкой этой длительности.

Для `generate_video` MCP читает длину в секундах или минутах из параметра `duration`
или однозначной фразы в промте. В `duration_matches` и строках моделей показаны подтверждённые, неподдержанные,
неопределённые и автоматические варианты; автоматическая длительность не обещает
точное число секунд. Полный список просматривается через `next_cursor`. Для
Video-to-Video передайте `video_path`/`video_url` или задайте `input_type="video"` при
сравнении. Строки `task_types`, `is_video_to_video_model` и `video_input_semantics`
отличают модели Video-to-Video от моделей с видеореференсом. У некоторых моделей поле
означает референс, а не покадровое редактирование.
Для лимита длительности исходника или суммы входа и результата задайте
`input_video_duration_seconds`; MCP сохраняет пользовательскую оценку в approval и не
измеряет ролик локально. На дату этой заметки Video-to-Video пока не проходил отдельную
live-приёмку; список моделей строится по текущим схеме и описанию KIE.

Только новые сохранения используют папки вида:
`2026-10-04__студийное-фото__image__google-nano-banana-edit__полный-ID-задачи`.
Дата — создание задачи в UTC, при отсутствии даты — текущая UTC; тип/расширение
определяются по фактическому файлу. Название добавляется через
`kie_download_result(task_id=..., result_label="студийное фото")` и необязательно.
Допустимы буквы, цифры, пробелы, дефисы и подчёркивания, максимум 48 байт UTF-8
(кириллическая буква обычно занимает два). Старые папки не переименовываются.
Повторное скачивание старой задачи создаёт файл по новому формату без перезаписи.
Ответ возвращает `output_path` и `output_folder`.

Пример: попросите агента «Создай короткое видео через KIE MCP, Seedance 2.0 Mini,
4 секунды, 480p, без звука; сначала покажи параметры и цену». Для оживления фото
добавьте путь к файлу в разрешённом uploads и описание движения.

```json
{
  "model": "bytedance/seedance-2-mini",
  "prompt": "A small paper boat gently floats on calm water. Slow camera push in.",
  "duration": 4,
  "resolution": "480p",
  "aspect_ratio": "16:9",
  "model_input": {"generate_audio": false},
  "dry_run": true
}
```

Эти аргументы передаются `generate_video`. Для фото добавьте один `image_path`
или `image_url`. MCP сопоставит изображение с `first_frame_url` актуальной схемы.
В текущей ситуации выбирайте Mini явно: дешёвая Seedance Lite дала provider 500;
автоматический router сравнивает совместимость/известные цены, без health scoring.

Все команды принимают `dry_run=true` и `model_input` для дополнительных полей
актуальной схемы. `edit_image`/`product_image_create` также принимают output_format.
Неизвестные/дублирующиеся параметры блокируются; сложные схемы требуют общих tools.

Friendly-команда готовит одну задачу, а не цепочку платных операций. Путь:
discovery → schema → preview → prepare → execute с теми же model/input/approval_id
→ wait/get_task → download в настроенный results root. Preview не резервирует
бюджет и не отправляет платную задачу, но локальное фото/внешняя ссылка могут быть
загружены в KIE для получения точного payload/digest. Для следующих шагов используйте
возвращённый request_payload, чтобы не загружать файл повторно и не менять запрос.

После обновления перезапустите MCP клиент/сессию для новых аргументов.
Проверки выполняйте последовательно: параллельный metadata preview получил 429;
в последующем последовательном проходе все семь задач завершились успешно.

## Ограничения и оставшиеся решения

- Расчёт цен покрывает reviewed профили в [PRICE_SUPPORT.md](PRICE_SUPPORT.md).
  Для неизвестного тарифа можно отдельно подтвердить риск: локально резервируется
  per-task limit, а списание KIE может быть выше. Mini промопрофиль истекает
  2026-10-07 06:00 UTC; затем нужен новый reviewed тариф, quote или такое согласие.
- «480p» — пресет модели: полученные видео имеют 864×496, не точные 480 px по высоте.
  Nano Banana однажды вернула JPEG вместо запрошенного PNG. MCP сохраняет фактический
  MIME/формат без скрытой конвертации; точный формат/размер требует отдельной операции.
- Анимация здесь — видео нейромодели. Timeline, точные keyframes, монтаж, титры,
  GIF/WebP экспорт и dedicated friendly audio-команда не реализованы. Разовая WebP
  конвертация ранее выполнена только по явному разрешению владельца.
- Код не гарантирует точного сохранения каждой буквы/геометрии нейромоделью.
  Студийное фото просмотрено; для товарного каталога результат проверяет владелец.
- Codex и Grok MCP calls приняты. Claude MCP подключён, но model-driven приёмка
  отложена из-за KIE chat 503, воспроизведённого без MCP.
- Подтверждение KIE-side caps/model policy и финальная owner acceptance ещё нужны,
  особенно до unattended работы; MCP не меняет эти настройки.
- По отчётам задач списано 40,7 кредита; общий баланс снизился на 59,78. История
  аккаунта нужна для атрибуции оставшихся 19,08; actual USD не предоставлен.
  Не обнулять ledger и не повторять неоднозначные платные отправки.
